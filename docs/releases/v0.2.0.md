# Modern-CCL v0.2.0 — Host/IG stack, mock IG viewer, fuzzing

Released 2026-10-12. Previous: `v0.1.0` (2026-10-08, foundation: wire layer, IG Control / Start of
Frame, field-table codec, `MessageBuilder` / `MessageView`, Wireshark frame example).

This release completes most of the Phase A MVP: a CIGI 3.3 Host can now connect to an IG over UDP
with a few lines of code, and a mock IG can be watched in a 3-D viewer. Not yet in this release:
the demo apps (`demo_host` / `demo_ig`, T09), CCL interoperability tests (T11) and the viewer's
network mode (T09b Part 2), so there is no network peer for `host_minimal` in the box yet; a real
CIGI 3.3 IG works.

## New

### Packets (T03–T05)
Entity Control, Component Control (+ typed component-data helpers), Articulated Part Control, Rate
Control, View Control, View Definition, Celestial Sphere Control, HAT/HOT Request, HAT/HOT Response,
HAT/HOT Extended Response — each with golden-byte tests in both byte orders.

### Dispatch (T06)
Packet sets (`HostToIgPackets`, `IgToHostPackets`, `Extend`, `Concat`), `decode_any`, a compile-time
`dispatch<Set>(view, visitor)` and a runtime `Dispatcher` with `on<P>` / `on_unknown` / `on_error`.
No allocation.

### Sessions (T07)
`HostSession` / `IgSession`: frame counters, IG mode rules (ICD §2.8), database requests,
stale/duplicate frame detection, optional outgoing validation, spdlog logging.

### UDP transport (T08)
Boost.Asio UDP endpoint, `platform::sleep_until` and a `FramePacer` (the only platform-specific
timing code is isolated there).

### High-level facade (T09a) — `cigi::Host`, `cigi::Ig` (`cigi_runtime`)
- `Host::connect({.ig_address = ...})`, `on_frame(HostFrame&)` to add packets each frame,
  `on<P>` for IG responses, `run(stop_token)` or `poll()`.
- Link-state machine: WaitingForIg → Standby → Operate / Debug, LoadingDatabase, Lost, with IG
  restart detection and database replay; `request_mode`, `request_database`, `stats()`.
- `cigi::Ig` for writing an IG (or a test double): learns its Host from the first valid message.
- `FaultInjectingTransport` (drop / duplicate / latency, seeded) and an in-memory transport pair
  for tests.
- Example: `examples/host_minimal.cpp`. Guide: `docs/guide/host-quickstart.md`.

### User-defined packets (T17)
Opcodes 201–255 declared like any other packet (field table gives byte swapping for free),
registered with `ExtendUser<Set, P...>`, size-checked by the builder (ICD §4.3), and switchable off
with `Dispatcher::ignore_user_packets` / `SessionConfig::ignore_user_packets`. Example:
`examples/user_packet.cpp`. In the facade, user packets currently arrive at `on_unknown`
(typed `on_user<P>` is planned: T09c).

### Mock IG and `ig_viewer` (T09b Part 1)
- `cigi_mock_ig`: headless mock-IG core (scene model, HAT/HOT answers from synthetic terrain, sky,
  scripted Host) shared with the coming `demo_ig`.
- `ig_viewer` (raylib + Dear ImGui, `-DCIGI_BUILD_VIEWER=ON`): 3-D view with Host / Chase / Free
  cameras, top-down map, entity table, packet inspector, HAT/HOT and IG logs; resizable panels and
  fullscreen (`F`). Guide: `docs/guide/ig-viewer.md`.

### Verification
- Wireshark/tshark verification of every MVP packet (T10): `docs/interop/wireshark.md`,
  discrepancies in `docs/interop/discrepancies.md`, `cigi::tools::PcapWriter`.
- libFuzzer (T12): `fuzz_message_view`, `fuzz_roundtrip` (full decode∘encode equality),
  `fuzz_sessions` (state invariants); corpora are replayed as ctests in every test build.
  `scripts/fuzz.sh [--linux]`. No crashes found (macOS ~11 min per target, Linux smoke runs).

## Quality
- Tests: 658 on macOS (Homebrew Clang: debug, ASan/UBSan, clang-tidy with zero warnings, coverage);
  655 on Linux GCC 14 (debug and ASan). Coverage: 98.3 % lines, 98.8 % functions, 96.0 % regions.
- No exceptions, no heap allocation in encode/decode/builder/view or the facade's steady-state
  frame path (tested).
- Every task was reviewed independently before merge; review follow-ups are listed in
  `docs/tasks/STATUS.md`.

## Known limitations
- Windows/MSVC builds are untested (planned for milestone M1).
- Typed user packets in the facade (`on_user<P>`), and the `user_packet` / `cigi_frames` examples
  on the facade: T09c.
- Host-requested Standby followed by one reordered stale frame can be counted as an IG restart
  (harmless start-up replay).
- `ig_viewer`: scripted Host only (network mode in T09b Part 2); `--stress` capped at 1000
  entities; macOS green-button fullscreen behaviour verified by hand only.
